화면을 보며 멍때리는 사이트

불멍 · 비멍 · 물멍. 장면은 크게, 조작은 작게. 소리를 켜고 아무 생각 없이 바라보는 곳.

디자인 시안 v0.22026.11.10모바일 우선 반응형물멍 세 장면 확정
코드로 구현됨 · src/ 이 보드의 화면은 src/에 구현돼 있어요(npm run dev). 각 화면 이름 옆 연결 파일에서 해당 코드를 볼 수 있어요. 불멍 소리는 실제 녹음(CC0), 비멍·물멍 소리는 아직 Web Audio 합성이에요. 보드에서는 장면을 직접 눌러 볼 수 있지만 소리는 나지 않아요.
아직 코드 없음 비멍의 ‘김 서린 창문 닦기’ 아이디어만 코드에 없어요. 구현하면서 추가 표시는 코드에 먼저 들어가고 보드에 나중에 적은 것이에요.

원칙

  1. 장면이 주인공화면 전체를 장면으로 채우고, 4초 동안 손대지 않으면 UI가 사라져요.
  2. 손대면 반응해요장작을 넣고, 비 세기를 바꾸고, 먹이를 줘요. 반응은 느리고 부드럽게.
  3. 소리가 절반실제 녹음한 소리를 반복 재생하고, 불 세기·비 세기에 맞춰 볼륨과 레이어가 바뀌어요.
  4. 한 손으로모바일은 엄지가 닿는 아래쪽에 조작을 모으고, 데스크톱은 단축키를 줘요.

홈

  • 첫 화면부터 세 장면이 실제로 움직이는 미리보기예요. 고르는 순간이 곧 멍때리기의 시작.
  • 카드를 누르는 동작이 사용자 제스처라서, 들어가자마자 소리를 바로 켤 수 있어요(자동재생 제한 회피).
  • 카드 왼쪽 위 태그로 장면마다 할 수 있는 것을 한 단어로 알려요.
  • 데스크톱은 카드에 마우스를 올리면 살짝 떠오르고, 소리를 작게 미리 들려줘요.

반응형

  • ~767px: 카드 세로 3장
  • 768~1199px: 카드 가로 3장, 높이 줄임
  • 1200px~: 카드 가로 3장, 숫자키로 바로 들어가기

장작이 타는 방식

  • 장작 3개로 시작해요. 하나가 1~2분에 걸쳐 갈색 → 숯 → 잔불로 타들어가고, 다 타면 짧아지며 사라져요.
  • 숯이 된 장작은 갈라진 틈이 주황색으로 숨 쉬듯 빛나요.
  • 장작 넣기: 위에서 ‘툭’ 떨어지며 불티가 튀고, 3초 동안 불이 옮겨붙은 뒤 불꽃이 커져요.
  • 불 세기 게이지는 남은 장작만큼 내려가요. 재촉하는 알림은 없어요.

조작

  • 모바일: 버튼을 누르거나, 트레이에서 장작을 끌어다 불에 놓아요.
  • 장작 종류(참나무·소나무·자작나무)는 타는 시간과 소리가 달라지는 선택 제안이에요.
  • 데스크톱: Space로 장작 넣기, 장면을 클릭해도 넣어져요.
  • 구현하면서 추가 트레이는 ‘장작 넣기’를 꾹 누르면 열려요. 처음 장작을 넣을 때 한 번 알려줘요.
  • 구현하면서 추가 장작 알아서 넣기(기본 켬): 20초 넘게 손대지 않았는데 불이 약해지면 장작을 하나씩 넣어요. 오래 멍때려도 불이 꺼지지 않게. 소리와 타이머 시트에서 끌 수 있어요.

소리

  • 타닥 소리 볼륨 = 불 세기. 장작 넣을 때 ‘툭’ + 불티 ‘파삭’.

장면

  • 창가에 앉아 밖을 보는 시점. 뒤로는 흐릿한 도시 불빛(보케)과 빗줄기, 앞으로는 유리창에 맺힌 물방울.
  • 큰 물방울이 멈췄다 흘렀다 하며 내려가고, 지나간 자리에 작은 물방울 자국을 남겨요.
  • 도로 쪽 불빛 몇 개는 천천히 옆으로 지나가요(차).

조작

  • 비 세기 3단계: 보슬비 / 비 / 장대비. 빗줄기 양, 흘러내리는 물방울, 소리가 함께 바뀌어요.
  • 천둥(선택): 켜면 20~40초에 한 번 번쩍이고, 1~2초 뒤 천둥소리.
  • 소리 시트에서 빗소리·천둥·바람을 따로 섞어요. 타이머도 여기서.

더 해볼 만한 것 아직 코드 없음

  • 김 서린 창문을 손가락으로 닦으면 그 자리만 선명해지고, 천천히 다시 흐려지기.

어항

  • ‘물멍’이 원래 어항을 보며 멍때리는 데서 온 말이라 가장 바로 이해돼요.
  • 먹이 주기라는 확실한 손맛이 있어요. 불멍의 장작 넣기와 짝이 맞아요.

조작

  • 물속을 톡 치면 그 자리에 먹이가 떨어지고, 가까운 물고기가 빠르게 모여들어요.
  • 못 먹은 먹이는 바닥에 가라앉았다 천천히 사라져요.
  • 소리: 여과기 물소리 + 보글보글, 먹이 줄 때 ‘퐁’.

몰입 모드

  • 4초 동안 입력이 없으면 UI가 1초에 걸쳐 사라져요. 데스크톱은 마우스 커서도 숨겨요.
  • 화면을 톡 치면(첫 번째 터치) 메뉴만 다시 나타나고, 장면에는 반응하지 않아요.
  • 보는 동안은 Wake Lock으로 화면이 꺼지지 않게 해요.

타이머 종료

  • 끝나기 3분 전부터 소리를 천천히 줄이고, 끝나면 ‘잘 멍때렸어요’ 카드.
  • 응답이 없으면 1분 뒤 장면도 어두워지며 멈춰요.

가로 화면

  • 조작을 오른쪽 세로 막대로 옮겨서 장면을 가리지 않아요.
  • 구현하면서 추가 비멍 · 바다에서는 가운데 버튼이 세기를 한 단계씩 바꿔요.

소리 켜기 구현하면서 추가

  • 링크로 바로 들어와서 아직 터치가 없으면 ‘탭해서 소리 켜기’ 안내가 떠요(브라우저 자동재생 제한).
