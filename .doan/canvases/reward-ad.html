05

기술 확인 · 정해야 할 것

만들기 전에 볼 것

되는지 — 돼요

  • 지금 깔린 @apps-in-toss/web-framework 3.10.0에 loadFullScreenAd · showFullScreenAd가 이미 들어 있어요. 새로 설치할 건 없어요.
  • 열림 기록은 기기 안에 저장해요(멍마다 연 날짜). 서버가 필요 없어요. 저장이 지워지면 다시 잠길 뿐이에요.
  • 토스 앱 5.227.0 이상에서 돼요. 그보다 낮으면 isSupported()가 false라 전부 열어 둬요.

순서

  1. 콘솔에서 리워드 광고 그룹 만들기. 이름 예: 멍열기_리워드. 보상 단위 · 수량은 사용자에게 보여서 ‘멍 1개’처럼 정해요. 만든 뒤 구글 등록까지 최대 2시간 걸려요.
  2. 테스트 ID로 만들기. 개발 중엔 ait-ad-test-rewarded-id를 써요. 운영 ID로 테스트하면 제재를 받을 수 있어요.
  3. 코드: src/lib/ads.ts를 배너 대신 리워드로 바꾸고, 잠금 확인은 src/app.ts 라우터 한 곳, 시트는 홈 · 장면 화면에 붙여요. 배너(showBanner, .home-ad)는 지워요.
  4. 테스트: 샌드박스 앱에서는 광고가 안 나와요. 콘솔의 QR로 실제 토스 앱에서 열어 봐요.
  5. 새 번들 올리고 검수. npm run build:ait → 콘솔에 업로드 → 검수 후 배포.

조심할 것

  • 보상은 userEarnedReward에서만. dismissed만 보고 열면 안 돼요(토스 문서에 명시).
  • 광고 중엔 앱 소리를 멈추고 끝나면 다시 틀어요(토스 정책). 이미 있는 audio.suspend() · resume()을 써요.
  • 광고가 끝난 뒤 소리. iOS는 광고가 끝나도 소리가 바로 안 돌아올 수 있어요. 그때는 지금 있는 ‘탭해서 소리 켜기’ 안내가 떠요. 실제 기기에서 확인이 필요해요.
  • 알려진 문제. 일부 안드로이드 토스 앱(5.255.0 · 5.266.0 등)은 dismissed가 안 올 때가 있어요. 보상을 받았으면 화면으로 돌아오는 순간에도 넘어가게 안전장치를 둬요.
  • 광고 그룹 ID는 하나씩만 미리 불러 둘 수 있어요. 광고를 보고 나면 다음 광고를 다시 불러요.

정한 것

  • 리워드(보상형) 광고로 열어요(04).
  • 불멍은 늘 무료, 나머지 다섯 멍은 광고 보고 열기.
  • 홈 배너는 없애요.

정해야 할 것

코드는 아래에서 제안한 쪽으로 먼저 들어갔어요: 오늘 하루 · 못 불러오면 그냥 열기 · 웹은 전부 열기 · 태그 ‘광고 보고 열기’. 바꾸려면 알려 주세요.

  • 한 번 보면 얼마나 열어 둘지.
    오늘 하루 (제안)들어갈 때마다몇 시간 (예: 3시간)한 번 보면 계속
    ‘계속’이면 한 사람이 평생 다섯 번만 봐서 수익이 거의 없고, ‘들어갈 때마다’면 멍때리러 왔다가 광고에 지쳐요. 하루가 가운데예요.
  • 광고를 못 불러올 때.
    그냥 열어 주기 (제안)‘잠시 후 다시’ 안내
    안내만 하면 iOS에서 앱 추적을 끈 사람은 계속 못 열 수 있어요.
  • 웹사이트 · 홈 화면 앱. 토스 광고를 붙일 수 없어서 전부 열어 두는 걸 제안해요. 잠그면 그냥 못 보는 멍이 돼요.
  • 잠긴 카드 표시. 태그를 ‘광고 보고 열기’로 바꿨어요(01). 자물쇠 아이콘만 두는 더 조용한 안도 있어요.
  • 보상 이름. 콘솔에서 정하는 보상 단위 · 수량이 광고 화면에 보여요. ‘멍 1개’를 제안해요.
