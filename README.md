# mong · 멍때리기 좋은 곳

불멍 · 비멍 · 물멍(어항 · 바다 · 연못) · 모래멍 · 별멍 · 눈멍(시계탑 · 발밑) · 지하철멍(맞은편 창 · 문 앞 · 창가). 소리를 켜고 아무 생각 없이 바라보는 사이트예요. 모바일부터 데스크톱까지 반응형이에요.

## 실행

```bash
npm install
npm run dev       # 개발 서버
npm run build     # 타입 검사 + dist/ 빌드
npm run build:ait # 위 빌드 + 토스 미니앱 출시용 번들(mong-time.ait, 실제 광고)
npm run build:ait:test # 토스 미니앱 테스트용 번들 (테스트 광고, 콘솔 QR 확인용)
npm run preview   # 빌드 결과 미리보기
```

Node 20.11 이상에서 동작해요. 토스 미니앱 번들(`build:ait`)은 Node 20.19 이상이 필요해요. 빌드 결과(`dist/`)는 정적 파일이라 어디에나 올릴 수 있어요. 주소는 해시(`#/fire`)를 써서 서버에 별도 라우팅 설정이 필요 없어요.

## 앱으로 설치 (PWA)

홈 화면에 추가하면 주소창 없이 앱처럼 열려요(`vite-plugin-pwa`, 설정은 `vite.config.ts`). 화면과 코드는 미리 저장해 두고, 녹음(19MB)은 브라우저에서는 처음 재생할 때 저장하고, 앱으로 설치하면 뒤에서 전부 받아 둬서 모든 장면이 오프라인에서도 소리가 나요(데이터 절약 모드에서는 받지 않아요). 새 버전은 뒤에서 받아 두었다가, 홈 화면에 있거나 아직 소리를 켜기 전이면 바로 새로고침해서 보여 주고, 멍 때리는 중이면 홈으로 돌아올 때 적용해요(`src/lib/update.ts`). 서비스 워커는 빌드 결과에서만 동작하니 `npm run build && npm run preview`로 확인해요.

## 토스 미니앱 광고

토스 앱 안에서만 **리워드(보상형) 광고**로 멍을 열어요(`src/lib/ads.ts`, 시트는 `src/views/unlock-sheet.ts`). 불멍은 늘 열려 있고, 나머지 여섯 멍은 짧은 광고를 끝까지 보면 그날 밤 12시까지 열려요(멍마다 연 날짜를 기기에 저장). 광고를 중간에 닫으면 잠긴 그대로이고, 보여 줄 광고가 없거나 5초 안에 못 불러오면 그냥 열어 줘요. 광고가 나오는 동안 앱 소리는 멈춰요. 홈 배너 광고는 없앴어요.

웹사이트와 홈 화면 앱에는 광고가 없어요. 토스 앱이 페이지에 넣어 주는 기능 정보(`window.__appsInTossConstants`)로 토스 앱 안인지 알아내고, 없으면 아무것도 잠그지 않고 광고 SDK도 불러오지 않아요. 같은 빌드(`dist/`)가 웹과 토스 번들 양쪽에 쓰여요.

광고 그룹 ID는 번들마다 달라요. 토스는 테스트할 때 반드시 테스트 ID를 쓰라고 해요(운영 ID로 테스트하면 제재를 받을 수 있어요).

| 무엇 | 광고 그룹 |
|---|---|
| `npm run build:ait` (출시용) | 콘솔의 리워드 광고 그룹 `ait.v2.live.54520b8e17e14da5` |
| `npm run build:ait:test` (콘솔 QR 테스트용) | 토스 테스트 광고 그룹 `ait-ad-test-rewarded-id` |
| `npm run dev` | 토스 테스트 광고 그룹 |

ID는 `src/lib/ads.ts`에 있어요. 샌드박스 앱에서는 광고가 안 나오니 테스트용 번들을 콘솔에 올려 QR로 실제 토스 앱에서 확인하고, 출시할 때는 출시용 번들을 올려요.

## 구조

```
src/
  app.ts               라우팅, 화면 전환
  views/
    home-view.ts       홈: 움직이는 미리보기 카드 7장 (폰은 두 칸 세 줄 + 맨 아래 넓은 지하철멍, 넓은 화면은 네 칸 두 줄)
    scene-view.ts      장면 화면: 탭(폰은 아이콘, 바꾸면 이름이 1초), 도크, 설정 시트(타이머 · 소리 섞기), 장작 트레이, 몰입 모드, 타이머 종료, 단축키
    unlock-sheet.ts    토스 미니앱: 잠긴 멍을 광고 보고 여는 시트
  scenes/              Canvas 2D 장면 (fire, rain, aquarium, sea, pond, sand, star, clocktower, underfoot, subway) + 눈멍 공용(snow.ts) + 공용 루프(host.ts)
  audio/
    engine.ts          AudioContext, 장면 간 크로스페이드, 홈 미리듣기, 타이머 페이드
    assets.ts          녹음 불러오기, 소리 안에서 ‘탁’·충돌 지점 찾기
    loop.ts            녹음 하나로 끝없이 이어지는 배경 소리 (무작위 구간 + 크로스페이드)
    sounds/            장면별 소리 (녹음 위에 짧은 순간만 합성음)
  lib/                 설정 저장(localStorage), 슬립 타이머, 화면 꺼짐 방지, 전체화면, 새 버전 적용, 토스 리워드 광고(ads.ts)
  styles/              tokens.css(디자인 토큰), app.css
```

## 소리

- **불멍**: 실제 녹음(CC0, `public/sounds/fire/`, 출처는 `public/sounds/CREDITS.md`). 모닥불 녹음 100초를 무작위 구간으로 이어 붙여(3초 크로스페이드) 반복이 티 나지 않게 하고, 불 세기에 따라 볼륨과 밝기가 바뀌어요. 같은 녹음에서 찾아낸 ‘탁’ 소리를 불 세기만큼 더하고, 장작을 넣으면 화면에서 장작이 닿는 순간에 맞춰 장작 소리(녹음된 세 가지 중 하나), 1.5초 뒤 불 붙는 소리가 나요. 여러 개를 한꺼번에 넣으면 하나씩 차례로 떨어지고, 장작 소리는 매번 다른 녹음으로 뒤로 갈수록 작게, 불 붙는 소리는 한 번만 조금 크게 나요. 장작은 서로 위에 쌓여(최대 8개) 더미가 높아지고 불꽃도 그만큼 커지며, 아래 장작이 타서 무너지면 위 장작이 내려앉아요.
- **비멍**: 실제 녹음(CC0, `public/sounds/rain/`). 보슬비 · 비 · 장대비마다 녹음이 따로 있고 세기를 바꾸면 2초쯤 걸쳐 크로스페이드해요. 원래 음량이 제각각이라(보슬비 -20, 비 -54, 장대비 -37 dBFS) 보슬비 < 비 < 장대비가 되도록 맞췄어요. 모노 녹음 두 벌을 서로 다른 지점에서 좌우로 벌려 스테레오처럼 들리게 하고, 번개 1~2초 뒤 천둥 녹음(매번 음높이·크기·방향을 조금씩 다르게), 창밖 바람 녹음을 깔아요.
- **물멍**: 아직 Web Audio 합성. 바다는 화면 파도와 같은 시계로 밀려와요.
- **모래멍**: 실제 녹음(CC0, `public/sounds/sand/`). 모래 붓는 녹음에서 끊기지 않는 31초를 무작위 구간으로 이어 붙이고, 떨어지는 양에 따라 소리가 커지고 밝아져요. 비우는 동안에는 모래시계 속 모래 소리가 끝날 때까지 이어져요.
- **별멍**: 실제 녹음(CC0, `public/sounds/star/`). 풀벌레 · 귀뚜라미 · 개구리 · 소쩍새 · 부엉이 · 밤바람 여섯 층이 계절마다 그 계절 것만 나고, 밤 깊이에 따라 크기가 달라져요. 풀벌레는 녹음 세 개가 밤 깊이를 따라 넘어가요(초저녁엔 먼 개구리가 섞인 들판, 한밤엔 잔잔한 울음, 새벽엔 가까운 한 마리 — `star.ts`의 `INSECT_MIX`). 소쩍새는 한동안 울다가 오래 쉬고, 부엉이는 녹음에 든 네 번의 울음 중 하나가 가끔 한 번씩 나요. 풀밭을 누르면 벌레와 개구리가 숨죽였다가 하나둘 다시 울어요. 녹음은 그 층이 들릴 때(계절 · 밤 깊이 · 소리 섞기) 처음 받아요. 소쩍새는 CC0 녹음이 없어 유럽소쩍새 녹음이에요.
- **눈멍**: 실제 녹음(CC0, `public/sounds/snow/`). 시계탑과 발밑이 같은 소리와 소리 섞기를 써요: 뽀드득(밟을 때마다 녹음된 스무 걸음 중 하나가 매번 다르게 나고, 눈을 쓸면 쓰는 동안 빗자루 녹음이 이어져요. 눈 쓰는 CC0 녹음이 없어 바깥 빗자루질 녹음이에요) · 눈 오는 밤(이 층만 Web Audio 합성. 먹먹한 공기와 낮은 바람, 눈이 셀수록 조금 더 사각거려요) · 먼 전차(평균 75초에 한 번, 땡 하고 멀어져 가는 전차 녹음) · 시계탑 종(시계 기준 10분마다 한 번, 종 녹음 한 번). 녹음을 받기 전이나 받지 못했을 때는 예전 합성음이 대신 나요.

- **지하철멍**: 실제 녹음(CC0, `public/sounds/subway/`, 듣기 보드 `.doan/canvases/subway-sound.html`에서 고른 것). 세 자리가 같은 소리와 소리 섞기를 써요: 열차(뉴욕 지하철이 윌리엄스버그 다리로 강을 건너는 녹음 150초를 무작위 구간으로 이어 붙여요. 레일 이음매마다 덜컹을 더하고, 철골 구간에서는 철교를 지나는 기차 녹음이 낮게 울려요) · 불꽃(화면에서 불꽃이 터지는 순간에 맞춰 펑. 두 불꽃축제 녹음에서 잘라 낸 펑 스무 개 중 하나를 매번 다르게, 큰 불꽃은 큰 펑으로, 음높이와 크기를 조금씩 바꿔서 창 너머로 먹먹하게 틀어요. 반짝이 불꽃은 타닥) · 차 안(역에 선 지하철 안의 웅웅 소리, 가끔 손잡이 끼익) · 사람들(차 안의 작은 말소리, 큰 불꽃에 조금 커져요. 처음엔 꺼져 있고 녹음은 이 층을 켤 때 받아요). 녹음을 받기 전이나 받지 못했을 때는 합성음이 대신 나요.

브라우저는 사용자가 한 번 누르기 전에는 소리를 못 내요. 홈에서 카드를 누르면 바로 소리가 나고, 링크로 바로 들어오면 ‘탭해서 소리 켜기’ 안내가 떠요.

## 디자인

Doan 보드 `.doan/canvases/mong.html`에 시안이 있고(모래멍은 `sand.html`, 별멍은 `star.html`, 눈멍은 `snow.html`, 지하철멍은 `subway.html`), 각 화면이 구현 파일과 연결돼 있어요(`data-doan-implements`).
